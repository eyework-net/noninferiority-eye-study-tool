# Ophthalmic Non-Inferiority Design Tool

眼科研究における非劣勢試験の設計を支援するための、HTMLベースの簡易ツールです。
非劣勢試験の流れをステップ形式で確認しながら、主要評価項目、非劣勢マージン、解析単位、両眼データ、反復測定、簡易症例数、推奨解析手法を整理できます。

## 概要

このツールは、眼科領域の研究デザインを想定して作成しています。

主な対象は以下です。

* IOL比較研究
* logMAR視力を用いた研究
* 屈折誤差・予測誤差の研究
* コントラスト感度研究
* スクリーニング・診断精度研究
* 合併症率・再手術率などの安全性研究

非劣勢試験では、「有意差がない」ことを示すだけでは不十分です。
本ツールでは、非劣勢マージンと信頼区間の関係を意識しながら、研究設計の抜け漏れを確認できるようにしています。

## 主な機能

* 非劣勢試験のステップ式チェックリスト
* 各ステップの進捗管理
* メモ保存機能
* 簡易症例数計算
* 脱落率を考慮した推奨n数表示
* logMAR、屈折誤差、コントラスト感度、二値アウトカムに対応
* 片眼・両眼・患者平均の選択
* 左右眼相関 ICC による簡易補正
* 反復測定、測定距離、術前値調整の考慮
* 推奨解析手法の自動表示
* Methods記載例の自動生成

## 使い方

1. `index.html` をブラウザで開きます。
2. 研究テーマ、主要評価項目、非劣勢マージン、標準偏差などを入力します。
3. 解析単位や反復測定の有無を選択します。
4. 推定n数と推奨解析手法を確認します。
5. 各ステップを順番にクリアしながら、研究設計を整理します。

## 注意事項

このツールで表示される症例数は、正規近似や簡易補正に基づく概算です。
実際の研究計画、倫理申請、論文投稿、学会発表に使用する場合は、統計ソフトまたは統計専門家による確認を推奨します。

特に以下の場合は、表示されたn数をそのまま採用しないでください。

* 両眼データを含む研究
* 反復測定を含む研究
* 3群以上の比較
* 多施設研究
* 低頻度イベントを扱う研究
* 診断精度研究
* 非正規分布の屈折誤差を扱う研究
* 欠測や脱落が多い研究

## 非劣勢試験における重要点

非劣勢試験では、以下を事前に明確にしておく必要があります。

* なぜ非劣勢試験として設計するのか
* 比較対象となる標準法は何か
* 主要評価項目は何か
* 非劣勢マージンはどのように決めたか
* 必要症例数はどのように計算したか
* ITT解析とper-protocol解析をどう扱うか
* どの信頼区間で非劣勢を判定するか
* 欠測、脱落、プロトコル逸脱をどう扱うか

## 推奨される解析の例

### 連続値アウトカム

例：logMAR視力、屈折誤差、コントラスト感度

* 平均差と95%信頼区間
* ANCOVA
* 線形回帰
* 線形混合効果モデル
* GEE

### 二値アウトカム

例：成功率、合併症率、再手術率

* リスク差と95%信頼区間
* Farrington–Manning検定
* ロジスティック回帰
* 一般化線形モデル
* GEE

### 両眼データ

両眼を解析に含める場合、左右眼を完全に独立したデータとして扱うことは推奨されません。
患者IDをランダム効果とする混合効果モデル、またはGEEなどを検討します。

## 免責事項

本ツールは、研究デザインの初期検討および学習支援を目的としたものです。
医学的判断、統計解析の最終判断、研究計画書の妥当性を保証するものではありません。

実際の研究では、研究目的、対象、評価項目、既報、臨床的意義、統計学的妥当性を踏まえて個別に検討してください。
